# 生成提示词与多视角规范

## 提示词编译

将已观察到的事实写入提示词，不将未替换的模板字段发送给工具。用清楚的分段即可，不要求连续长句；双语只在用户要求时提供。

推荐组织顺序：

- 任务与输出：产品品类、改动幅度、主视图或提案板。
- 参考分工：A 提供可见功能架构；B（如有）只提供指定风格特征；已认可主视图（如有）是后续外观一致性的基准。
- 硬约束：具体功能件、数量、相互位置、连接关系与使用方式。
- 形体策略：一句整体策略，加 2–3 个体块与表面组织的具体动作。
- 风格映射：每个参考特征映射到哪个外观区域；明确哪些特征不适用。
- CMF：主体材质与颜色、少量强调色、表面观感和分件边界。不把视觉估计写成测量事实。
- 相机与画面：沿用 A 的可见视角或执行用户指定视角，清晰完整、背景简洁。
- 针对性限制：例如保护按键和滚轮的实体形态，避免将参考图镂空纹样迁移到功能件；不堆叠无关负面词。

约束发生冲突时，先满足用户明确要求和功能锁定，再处理风格表达与画面装饰；用户明确要求改变功能时更新锁定表，不沿用过期约束。

## 多视角扩展

将认可或自行检查通过的主视图作为图像参考继续生成，而非仅凭上一轮文字重新想象设计。原始 A 继续约束功能，B 只负责风格，不允许覆盖已确定外观。

默认提案板为 16:9：一张较大的 3/4 主视图、正面/侧面/背面，以及 2–3 个有信息价值且不重复的细节。以用户指定的数量和布局优先；不为凑满版面生成无法判断的隐藏功能。

跨视角重复写入关键不变量：轮廓逻辑、体块比例、分件走向、功能件数量与位置关系、材质分区。文字强调并不能保证一致，必须目视对照。明显不一致的视图不能称为准确三视图。

隐藏面只补全外壳形式，不凭空补充接口和机构。背面信息不足时在交付说明中标注推演，或在准确性必要时先取得补充参考。

使用浅色工作室背景、适度接触阴影与清晰材质表达，除非用户另有要求。避免大量微型文字；用户需要生产用文字时，将它与概念渲染中的视觉占位区分。
